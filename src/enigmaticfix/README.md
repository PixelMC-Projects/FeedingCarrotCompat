# PixelMC Enigmatic Startup Fix

[中文](#中文) · [English](#english)

## 中文

修复指定版本神秘遗物相关模组在启动阶段的并发加载问题。

### 功能

- 将相关启动处理按顺序执行，保留原有配方与玩法。
- 生成独立补丁 JAR，不要求安装喂食兼容模组。

### 使用

适用于 Minecraft **1.20.1 / Forge**，针对 Enigmatic Legacy **2.30.1**、Enigmatic Addons **1.2.5** 和 Enigmatic Delicacy **1.0.1**。按所用模组版本安装到客户端或服务端。

## English

Fix a concurrent startup-loading issue in specific Enigmatic mod versions.

### Features

- Run affected startup handlers sequentially while retaining recipes and gameplay.
- Build a separate patch JAR that does not require the feeding compatibility mod.

### Usage

For Minecraft **1.20.1 / Forge**, targeting Enigmatic Legacy **2.30.1**, Enigmatic Addons **1.2.5**, and Enigmatic Delicacy **1.0.1**. Install on clients or servers using the matching mods.
